# 직렬화, 역직렬화

직렬화(Serialization)는 메모리 내의 객체나 데이터 구조를 저장 및 네트워크 전송이 가능한 형태(바이트 스트림 또는 문자열)로 변환하는 과정이며, 역직렬화(Deserialization)는 이 데이터를 읽어 다시 메모리 상의 프로그램 객체로 복원하는 과정입니다.

## 1. 직렬화와 역직렬화가 필요한 이유

컴퓨터의 메모리(RAM)에 존재하는 객체는 메모리 주소(포인터)를 참조하여 연결된 복잡한 구조를 가집니다. RAM은 전원이 꺼지면 데이터가 날아가며, 메모리 주소는 해당 컴퓨터의 특정 시점에만 유효하므로 이를 그대로 디스크에 저장하거나 타 시스템으로 보낼 수 없습니다.

- **직렬화 (Serialization):** 메모리의 입체적인 객체 구조를 1차원의 연속적인 바이트 스트림(Byte Stream)이나 문자열(JSON, XML 등)로 펼쳐서 파일 저장이나 네트워크 전송이 가능하게 만듭니다.
- **역직렬화 (Deserialization):** 전송받은 바이트 스트림을 해석하여 메모리 주소를 다시 재할당하고, 원래 객체의 상태와 데이터 구조를 복원합니다.

## 2. 파이썬의 Pickling (`pickle` 모듈)

파이썬의 `pickle`은 파이썬 전용의 객체 직렬화 표준 모듈입니다. 파이썬 객체 구조를 바이트 스트림으로 변환하는 과정을 **Pickling**, 반대로 바이트 스트림에서 객체를 복원하는 과정을 **Unpickling**이라고 부릅니다.

```jsx
import pickle

# 1. 직렬화할 파이썬 데이터 (딕셔너리, 리스트 등)
data = {
    'user_id': 1004,
    'roles': ['admin', 'developer'],
    'is_active': True
}

# 2. Pickling: 객체 -> 바이너리 바이트 스트림 (dumps)
serialized_bytes = pickle.dumps(data)
print("직렬화된 바이트:", serialized_bytes)

# 3. Unpickling: 바이너리 바이트 스트림 -> 객체 복원 (loads)
restored_data = pickle.loads(serialized_bytes)
print("복원된 데이터:", restored_data)
print("타입 확인:", type(restored_data)) # <class 'dict'>
```

Pickle과 JSON 비교

| **구분** | **pickle** | **json** |
| --- | --- | --- |
| **호환성** | 파이썬 전용 (다른 언어와 호환 불가) | 범용적 (모든 언어 및 플랫폼 호환) |
| **데이터 형태** | 바이너리 (Binary) | 사람이 읽을 수 있는 텍스트 |
| **지원 객체** | 파이썬 커스텀 클래스, 함수, 튜플, 세트 등 거의 모든 객체 | 기본 타입 위주 (`dict`, `list`, `str`, `int`, `bool` 등) |
| **주요 용도** | 파이썬 프로세스 간 객체 전달, 머신러닝 모델 저장 | Web API 통신, 설정 파일, 다른 언어와의 데이터 교환 |

`pickle`은 역직렬화(Unpickling) 과정에서 객체의 생성자 및 내부 메서드를 실행합니다. 따라서 **신뢰할 수 없는 외부 사용자로부터 전달받은 피클 데이터를 `pickle.load()`로 읽을 경우, 원격 코드 실행(RCE) 공격에 노출될 수 있습니다.** 외부 네트워크 전송용으로는 반드시 **JSON**이나 **Protocol Buffers**를 사용하는 것이 권장됩니다.
