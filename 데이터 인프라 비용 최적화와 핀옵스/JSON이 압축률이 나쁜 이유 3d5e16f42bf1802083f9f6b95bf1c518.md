# JSON이 압축률이 나쁜 이유

## 1. KEY의 반복적인 사용

- JSON은 각 레코드마다 데이터의 필드명을 반복하여 포함하는 구조이다

```jsx
[
  {"id": 1, "name": "Kim", "age": 30},
  {"id": 2, "name": "Lee", "age": 25}
]
```

위의 데이터 양이 늘어날 수록 “id”,”name”,”age”가 계속 반복된다. 그로인해, 전체 파일에서 KEY가 차지하는 비중이 커진다. 커진 비중은 결국 용량 낭비가 심해지게 된다.

## 2. 모든 데이터의 String 변환

JSON은 모든 데이터가 문자열로 저장되는 포맷이다.

예를 들어 숫자 100000000를 정수형으로 저장한다면 4바이트이지만, 텍스트인 JSON에서는 글자수로 판별하여 9바이트를 차지한다. 

이로 인해 데이터 크기가 커지게 되어 압축하는데 한계가 발생한다.

## 3. 구문 및 포맷팅 오버헤드

데이터의 실제 값 외에도 중괄호, 대괄호 등 문법을 유지하기 위한 기호들이 상당한 공간을 차지한다.

또한 사람이 읽기 쉽게 들여쓰기와 줄바꿈이 포함되어 있으므로 파일의 크기가 늘어날 수 밖에 없다.
